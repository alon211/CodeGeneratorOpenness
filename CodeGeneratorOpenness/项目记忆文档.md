# 项目记忆文档

## 图标索引常量管理

### 功能描述
项目中使用TreeView控件显示PLC项目结构，每个节点都有对应的图标索引。为了提高代码可维护性，将硬编码的图标索引替换为常量引用。

### 相关组件和函数
- **文件**: `cFunctionGroups.cs`
- **主要类**: `cFunctionGroups`
- **关键常量**:
  - `DEFAULT_ICON_INDEX = 0` - 默认图标
  - `FOLDERCLOSED_ICON_INDEX = 1` - 文件夹关闭图标
  - `OB_ICON_INDEX = 2` - OB块图标
  - `FC_ICON_INDEX = 3` - FC块图标
  - `FB_ICON_INDEX = 7` - FB块图标
  - `DB_ICON_INDEX = 5` - DB块图标
  - `SAFEOB_ICON_INDEX = 4` - 安全OB块图标
  - `SAFEFB_ICON_INDEX = 8` - 安全FB块图标
  - `SAFEDB_ICON_INDEX = 6` - 安全DB块图标
  - `DATATYPE_ICON_INDEX = 9` - 数据类型图标
  - `TAG_TABLE_ICON_INDEX = 10` - 标签表图标
  - `SOFTWARE_UNITS_ICON_INDEX = 11` - 软件单元图标


### 调用逻辑
1. 在TreeView节点创建时，使用常量而不是硬编码数字设置ImageIndex和SelectedImageIndex
2. 根据不同的PLC对象类型（OB、FB、FC、DB等）选择对应的图标常量
3. 对于安全相关的块，使用对应的安全图标常量
4. 文件夹类型的节点统一使用FOLDERCLOSED_ICON_INDEX
