## 图标索引常量管理

### 功能描述
项目中使用TreeView控件显示PLC项目结构，每个节点都有对应的图标索引。为了提高代码可维护性，将硬编码的图标索引替换为常量引用。

### 相关组件和函数
- **文件**: `cFunctionGroups.cs`
- **主要类**: `cFunctionGroups`
- **关键常量**:
  - `DEFAULT_ICON_INDEX = 0` - 默认图标
  - `FOLDERCLOSED_ICON_INDEX = 1` - 文件夹关闭图标
  - `OB_ICON_INDEX = 2` - OB块图标
  - `FC_ICON_INDEX = 3` - FC块图标
  - `FB_ICON_INDEX = 7` - FB块图标
  - `DB_ICON_INDEX = 5` - DB块图标
  - `SAFEOB_ICON_INDEX = 4` - 安全OB块图标
  - `SAFEFB_ICON_INDEX = 8` - 安全FB块图标
  - `SAFEDB_ICON_INDEX = 6` - 安全DB块图标
  - `DATATYPE_ICON_INDEX = 9` - 数据类型图标
  - `TAG_TABLE_ICON_INDEX = 10` - 标签表图标
  - `SOFTWARE_UNITS_ICON_INDEX = 11` - 软件单元图标

### 调用逻辑
1. 在TreeView节点创建时，使用常量而不是硬编码数字设置ImageIndex和SelectedImageIndex
2. 根据不同的PLC对象类型（OB、FB、FC、DB等）选择对应的图标常量
3. 对于安全相关的块，使用对应的安全图标常量
4. 文件夹类型的节点统一使用FOLDERCLOSED_ICON_INDEX

```csharp
public static class DirectoryUtils
{
    /// <summary>
    /// 确保相对路径存在，如果不存在则递归创建多级目录
    /// </summary>
    /// <param name="relativePath">相对于应用程序目录的路径</param>
    /// <returns>创建成功返回true，失败返回false</returns>
    public static bool EnsureDirectoryExists(string relativePath)
    {
        if (string.IsNullOrWhiteSpace(relativePath))
        {
            Logger.LogWarning("相对路径不能为空", "DirectoryUtils.EnsureDirectoryExists");
            return false;
        }

        try
        {
            string fullPath = GetFullPath(relativePath);
            Logger.LogInfo($"检查目录路径: {fullPath}", "DirectoryUtils.EnsureDirectoryExists");

            if (Directory.Exists(fullPath))
            {
                Logger.LogInfo($"目录已存在: {fullPath}", "DirectoryUtils.EnsureDirectoryExists");
                return true;
            }

            Directory.CreateDirectory(fullPath);
            Logger.LogInfo($"目录创建成功: {fullPath}", "DirectoryUtils.EnsureDirectoryExists");
            return true;
        }
        catch (Exception ex)
        {
            Logger.LogException(ex, "DirectoryUtils.EnsureDirectoryExists");
            return false;
        }
    }

    /// <summary>
    /// 批量创建多个相对路径目录
    /// </summary>
    /// <param name="relativePaths">相对路径数组</param>
    /// <returns>全部创建成功返回true</returns>
    public static bool EnsureDirectoriesExist(string[] relativePaths)
    {
        if (relativePaths == null || relativePaths.Length == 0)
        {
            Logger.LogWarning("路径数组不能为空", "DirectoryUtils.EnsureDirectoriesExist");
            return false;
        }

        bool allSuccess = true;
        foreach (string path in relativePaths)
        {
            if (!EnsureDirectoryExists(path))
            {
                allSuccess = false;
            }
        }
        return allSuccess;
    }
}
```

## 项目树JSON导出功能实现

### 功能描述
项目打开并生成树结构后，自动将TreeView结构导出为JSON格式文件，保存到指定目录。该功能通过JsonExporter类实现，支持完整的树结构序列化，包括节点名称、标签信息、层级关系等。

### 相关组件和函数
- **文件**: `cJsonExporter.cs`
- **主要类**: `JsonExporter` (静态工具类)
- **核心方法**:
  - `ExportTreeViewToJson(TreeView treeView, string outputPath, string fileName)` - 导出TreeView到JSON文件
  - `ConvertTreeViewToJson(TreeView treeView)` - 将TreeView转换为JSON对象
  - `ConvertTreeNodeToJson(TreeNode node)` - 递归转换TreeNode为JSON对象
  - `ExtractTagInfo(object tag)` - 提取节点标签信息
  - `CreateExportInfo()` - 创建导出元信息
  - `SaveJsonToFile(JObject jsonObject, string filePath)` - 保存JSON对象到文件
  - `GetJsonFileStats(string filePath)` - 获取JSON文件统计信息

### 调用逻辑
1. **触发时机**: 在`frmMainForm.cs`的`IterateThroughDevices`方法中，项目树加载完成后自动触发
2. **路径配置**: 使用`Program.PROJECT_TREENODE_JSON_PATH`常量定义的输出路径
3. **文件命名**: 以当前打开的项目名称作为JSON文件名
4. **异常处理**: 完整的try-catch异常处理和日志记录
5. **状态反馈**: 通过日志记录导出成功或失败状态

### 实现方法

#### 1. JsonExporter类核心实现
```csharp
public static class JsonExporter
{
    /// <summary>
    /// 导出TreeView到JSON文件
    /// </summary>
    /// <param name="treeView">要导出的TreeView控件</param>
    /// <param name="outputPath">输出目录路径</param>
    /// <param name="fileName">文件名（不含扩展名）</param>
    /// <returns>导出成功返回true</returns>
    public static bool ExportTreeViewToJson(TreeView treeView, string outputPath, string fileName)
    {
        try
        {
            // 转换TreeView为JSON对象
            JObject jsonObject = ConvertTreeViewToJson(treeView);
            
            // 构建完整文件路径
            string fullPath = Path.Combine(outputPath, $"{fileName}.json");
            
            // 保存到文件
            return SaveJsonToFile(jsonObject, fullPath);
        }
        catch (Exception ex)
        {
            Logger.LogException(ex, "JsonExporter.ExportTreeViewToJson");
            return false;
        }
    }

    /// <summary>
    /// 将TreeView转换为JSON对象
    /// </summary>
    private static JObject ConvertTreeViewToJson(TreeView treeView)
    {
        JObject result = new JObject();
        
        // 添加导出信息
        result["ExportInfo"] = CreateExportInfo();
        
        // 转换根节点
        JArray rootNodes = new JArray();
        foreach (TreeNode rootNode in treeView.Nodes)
        {
            rootNodes.Add(ConvertTreeNodeToJson(rootNode));
        }
        result["RootNodes"] = rootNodes;
        
        return result;
    }
}
```

```csharp
private void CheckFilePathExists(string filePath)
{
    try
    {
        cLogger.LogInfo("CheckFilePathExists", $"开始检查文件路径: {filePath}");
        
        string absolutePath;
        
        // 判断是否为绝对路径
        if (System.IO.Path.IsPathRooted(filePath))
        {
            absolutePath = filePath;
        }
        else
        {
            // 相对路径转换为绝对路径
            absolutePath = System.IO.Path.Combine(Application.StartupPath, filePath);
        }
        
        cLogger.LogInfo("CheckFilePathExists", $"转换后的绝对路径: {absolutePath}");
        
        // 检查文件是否存在
        if (System.IO.File.Exists(absolutePath))
        {
            cLogger.LogInfo("CheckFilePathExists", $"文件路径存在: {absolutePath}");
        }
        else
        {
            cLogger.LogWarning("CheckFilePathExists", $"文件路径不存在: {absolutePath}");
            
            // 弹窗提示用户文件不存在，并退出程序
            MessageBox.Show($"模板文件不存在：\n{absolutePath}\n\n程序将退出。", 
                          "错误", 
                          MessageBoxButtons.OK, 
                          MessageBoxIcon.Error);
            
            cLogger.LogError("CheckFilePathExists", "模板文件不存在，程序将退出");
            Application.Exit();
        }
    }
    catch (Exception ex)
    {
        cLogger.LogError("CheckFilePathExists", $"检查文件路径时发生异常: {ex.Message}");
        
        // 异常情况下也弹窗提示并退出
        MessageBox.Show($"检查文件路径时发生异常：\n{ex.Message}\n\n程序将退出。", 
                      "错误", 
                      MessageBoxButtons.OK, 
                      MessageBoxIcon.Error);
        Application.Exit();
    }
}
```

```csharp
private void CreateNewProject()
{
    try
    {
        // 1. 获取用户输入的项目名称
        string projectName = Input.InputBox("请输入新项目名称:", "新建项目", "");
        
        if (string.IsNullOrWhiteSpace(projectName))
        {
            Logger.LogInfo("用户取消了项目名称输入", "CreateNewProject");
            return;
        }
        
        // 2. 验证和清理项目名称
        projectName = projectName.Trim();
        char[] invalidChars = Path.GetInvalidFileNameChars();
        if (projectName.IndexOfAny(invalidChars) >= 0)
        {
            MessageBox.Show("项目名称包含无效字符，请重新输入。", "错误", MessageBoxButtons.OK, MessageBoxIcon.Warning);
            return;
        }
        
        Logger.LogInfo($"用户输入的项目名称: {projectName}", "CreateNewProject");
        
        // 3. 检查模板文件是否存在
        string templatePath = Path.Combine(Application.StartupPath, "template", "Automation_Framework_PROJ_V1_2", "Automation_Framework_PROJ_V1_2.ap19");
        if (!File.Exists(templatePath))
        {
            MessageBox.Show($"模板文件不存在: {templatePath}", "错误", MessageBoxButtons.OK, MessageBoxIcon.Error);
            Logger.LogError($"模板文件不存在: {templatePath}", "CreateNewProject");
            return;
        }
        
        // 4. 确保project目录存在
        string projectDir = Path.Combine(Application.StartupPath, "project");
        if (!Directory.Exists(projectDir))
        {
            Directory.CreateDirectory(projectDir);
            Logger.LogInfo($"创建project目录: {projectDir}", "CreateNewProject");
        }
        
        // 5. 检查目标项目目录
        string targetProjectDir = Path.Combine(projectDir, projectName);
        if (Directory.Exists(targetProjectDir))
        {
            var result = MessageBox.Show($"项目 '{projectName}' 已存在，是否覆盖？", "确认", MessageBoxButtons.YesNo, MessageBoxIcon.Question);
            if (result != DialogResult.Yes)
            {
                Logger.LogInfo($"用户取消覆盖现有项目: {projectName}", "CreateNewProject");
                return;
            }
            
            // 删除现有目录
            Directory.Delete(targetProjectDir, true);
            Logger.LogInfo($"删除现有项目目录: {targetProjectDir}", "CreateNewProject");
        }
        
        // 6. 创建项目目录
        Directory.CreateDirectory(targetProjectDir);
        Logger.LogInfo($"创建新项目目录: {targetProjectDir}", "CreateNewProject");
        
        // 7. 从模板创建项目
        CreateProjectFromTemplate(templatePath, targetProjectDir, projectName);
        
        // 8. 询问是否打开新创建的项目
        var openResult = MessageBox.Show($"项目 '{projectName}' 创建成功！是否立即打开？", "成功", MessageBoxButtons.YesNo, MessageBoxIcon.Information);
```

```csharp
private void CreateProjectFromTemplate(string templatePath, string targetProjectDir, string projectName)
{
    TiaPortal tiaPortal = null;
    Project project = null;
    
    try
    {
        Logger.LogInfo($"开始从模板创建项目: {templatePath} -> {targetProjectDir}", "CreateProjectFromTemplate");
        
        // 1. 创建TIA Portal实例
        tiaPortal = new TiaPortal(TiaPortalMode.WithoutUserInterface);
        Logger.LogInfo("TIA Portal实例创建成功", "CreateProjectFromTemplate");
        
        // 2. 打开模板项目
        project = tiaPortal.Projects.Open(new FileInfo(templatePath));
        Logger.LogInfo($"模板项目打开成功: {templatePath}", "CreateProjectFromTemplate");
        
        // 3. 构建新项目的完整路径
        string newProjectPath = Path.Combine(targetProjectDir, $"{projectName}.ap19");
        Logger.LogInfo($"新项目保存路径: {newProjectPath}", "CreateProjectFromTemplate");
        
        // 4. 保存项目到新位置
        project.SaveAs(new FileInfo(newProjectPath));
        Logger.LogInfo($"项目保存成功: {newProjectPath}", "CreateProjectFromTemplate");
        
        MessageBox.Show($"项目 '{projectName}' 创建成功！\n保存位置: {newProjectPath}", "成功", MessageBoxButtons.OK, MessageBoxIcon.Information);
    }
    catch (Exception ex)
    {
        Logger.LogException(ex, "CreateProjectFromTemplate");
        throw; // 重新抛出异常，让调用方处理
    }
    finally
    {
        // 5. 清理资源
        try
        {
            if (project != null)
            {
                project.Close();
                Logger.LogInfo("模板项目已关闭", "CreateProjectFromTemplate");
            }
            
            if (tiaPortal != null)
            {
                tiaPortal.Dispose();
                Logger.LogInfo("TIA Portal实例已释放", "CreateProjectFromTemplate");
            }
        }
        catch (Exception ex)
        {
            Logger.LogException(ex, "CreateProjectFromTemplate.Finally");
        }
    }
}
```
