## 图标索引常量管理

### 功能描述
项目中使用TreeView控件显示PLC项目结构，每个节点都有对应的图标索引。为了提高代码可维护性，将硬编码的图标索引替换为常量引用。

### 相关组件和函数
- **文件**: `cFunctionGroups.cs`
- **主要类**: `cFunctionGroups`
- **关键常量**:
  - `DEFAULT_ICON_INDEX = 0` - 默认图标
  - `FOLDERCLOSED_ICON_INDEX = 1` - 文件夹关闭图标
  - `OB_ICON_INDEX = 2` - OB块图标
  - `FC_ICON_INDEX = 3` - FC块图标
  - `FB_ICON_INDEX = 7` - FB块图标
  - `DB_ICON_INDEX = 5` - DB块图标
  - `SAFEOB_ICON_INDEX = 4` - 安全OB块图标
  - `SAFEFB_ICON_INDEX = 8` - 安全FB块图标
  - `SAFEDB_ICON_INDEX = 6` - 安全DB块图标
  - `DATATYPE_ICON_INDEX = 9` - 数据类型图标
  - `TAG_TABLE_ICON_INDEX = 10` - 标签表图标
  - `SOFTWARE_UNITS_ICON_INDEX = 11` - 软件单元图标

### 调用逻辑
1. 在TreeView节点创建时，使用常量而不是硬编码数字设置ImageIndex和SelectedImageIndex
2. 根据不同的PLC对象类型（OB、FB、FC、DB等）选择对应的图标常量
3. 对于安全相关的块，使用对应的安全图标常量
4. 文件夹类型的节点统一使用FOLDERCLOSED_ICON_INDEX

### 实现方法
- `AddPlcBlocks()` - 添加PLC块节点
- `AddPlcTypes()` - 添加PLC类型节点
- `AddTagTables()` - 添加标签表节点
- `AddExternalSources()` - 添加外部源节点
- `AddTechnologicalObjects()` - 添加工艺对象节点
- `AddWatchForceTables()` - 添加监视强制表节点
- `LoadBlockGroup()` - 加载块组
- `LoadTypeGroup()` - 加载类型组
- `LoadTagTableGroup()` - 加载标签表组
- `LoadExternalSourceGroup()` - 加载外部源组
- `LoadPlcAlarmTextlistGroup()` - 加载PLC报警文本列表组
- `LoadWatchAndForceTableGroup()` - 加载监视和强制表组
- `LoadSoftwareUnitsGroup()` - 加载软件单元组
- `AddSoftwareUnitComponents()` - 添加软件单元组件
- `AddTagTableGroup()` - 添加标签表组
- `AddExternalSourceGroup()` - 添加外部源组

## 目录创建功能实现

### 功能描述
项目启动时自动创建必要的目录结构，确保程序运行所需的文件夹存在。通过模块化的DirectoryUtils工具类实现目录的创建、检查和管理功能。

### 相关组件和函数
- **文件**: `cDirectoryUtils.cs`
- **主要类**: `DirectoryUtils` (静态工具类)
- **核心方法**:
  - `EnsureDirectoryExists(string relativePath)` - 确保单个相对路径目录存在
  - `EnsureDirectoriesExist(string[] relativePaths)` - 批量创建多个相对路径目录
  - `GetFullPath(string relativePath)` - 获取相对路径的完整绝对路径
  - `DirectoryExists(string relativePath)` - 检查相对路径目录是否存在
  - `GetApplicationDirectory()` - 获取当前应用程序目录

### 调用逻辑
1. **程序启动时初始化**: 在`Program.cs`的`Main`方法中调用`InitializeDirectories()`
2. **目录结构定义**: 在`InitializeDirectories`方法中定义需要创建的目录数组
3. **批量创建**: 使用`DirectoryUtils.EnsureDirectoriesExist`批量创建所有目录
4. **日志记录**: 记录目录初始化状态和异常信息

### 实现方法

#### 1. DirectoryUtils工具类实现
```csharp
public static class DirectoryUtils
{
    /// <summary>
    /// 确保相对路径存在，如果不存在则递归创建多级目录
    /// </summary>
    /// <param name="relativePath">相对于应用程序目录的路径</param>
    /// <returns>创建成功返回true，失败返回false</returns>
    public static bool EnsureDirectoryExists(string relativePath)
    {
        if (string.IsNullOrWhiteSpace(relativePath))
        {
            Logger.LogWarning("相对路径不能为空", "DirectoryUtils.EnsureDirectoryExists");
            return false;
        }

        try
        {
            string fullPath = GetFullPath(relativePath);
            Logger.LogInfo($"检查目录路径: {fullPath}", "DirectoryUtils.EnsureDirectoryExists");

            if (Directory.Exists(fullPath))
            {
                Logger.LogInfo($"目录已存在: {fullPath}", "DirectoryUtils.EnsureDirectoryExists");
                return true;
            }

            Directory.CreateDirectory(fullPath);
            Logger.LogInfo($"目录创建成功: {fullPath}", "DirectoryUtils.EnsureDirectoryExists");
            return true;
        }
        catch (Exception ex)
        {
            Logger.LogException(ex, "DirectoryUtils.EnsureDirectoryExists");
            return false;
        }
    }

    /// <summary>
    /// 批量创建多个相对路径目录
    /// </summary>
    /// <param name="relativePaths">相对路径数组</param>
    /// <returns>全部创建成功返回true</returns>
    public static bool EnsureDirectoriesExist(string[] relativePaths)
    {
        if (relativePaths == null || relativePaths.Length == 0)
        {
            Logger.LogWarning("路径数组不能为空", "DirectoryUtils.EnsureDirectoriesExist");
            return false;
        }

        bool allSuccess = true;
        foreach (string path in relativePaths)
        {
            if (!EnsureDirectoryExists(path))
            {
                allSuccess = false;
            }
        }
        return allSuccess;
    }
}
```

#### 2. Program.cs中的初始化实现
```csharp
// 在Main方法中添加目录初始化调用
static void Main()
{
    // ... 现有代码 ...
    AppDomain.CurrentDomain.AssemblyResolve += MyResolver;
    
    // 初始化目录结构
    InitializeDirectories();
    
    Application.Run(new frmMainForm());

/// <summary>
/// 初始化程序运行所需的目录结构
/// </summary>
private static void InitializeDirectories()
{
    try
    {
        string[] requiredDirectories = {
            "project",              // 项目文件目录
            "template",             // 模板文件目录
            "Output",               // 输出根目录
            "Output\\Log",           // 日志目录
            "Output\\Result",       // 结果文件目录
            "Output\\Reports",      // 报告目录
            "Data",                 // 数据目录
            "UserLibrary"           // 用户库目录
        };

        DirectoryUtils.EnsureDirectoriesExist(requiredDirectories);
        Logger.LogInfo("目录结构初始化完成", "Program.InitializeDirectories");
    }
    catch (Exception ex)
    {
        Logger.LogException(ex, "Program.InitializeDirectories");
    }
}
```

### 创建的目录结构
程序启动时会自动创建以下目录结构：
```
应用程序根目录/
├── project/              # 项目文件目录
├── template/             # 模板文件目录
├── Output/               # 输出根目录
│   ├── Log/             # 日志目录
│   ├── Result/          # 结果文件目录
│   └── Reports/         # 报告目录
├── Data/                 # 数据目录
└── UserLibrary/          # 用户库目录
```

### 特性和优势
1. **模块化设计**: DirectoryUtils作为独立的静态工具类，可在项目其他地方复用
2. **相对路径支持**: 所有路径都基于应用程序目录的相对路径，便于部署
3. **递归创建**: 支持多级目录的递归创建
4. **批量操作**: 支持一次性创建多个目录
5. **完善的日志**: 详细记录目录创建过程和状态
6. **异常处理**: 完善的错误处理机制，确保程序稳定性
7. **启动时初始化**: 程序启动时自动创建，无需手动干预
